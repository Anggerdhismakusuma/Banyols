## ✨ Features

🔐 Login & authentication with input validation (username, password alphanumeric)<br>
🏠 Personalized home page with greeting and navigation menu<br>
📚 Browse classic books – Fiction & Non‑Fiction categories<br>
⭐ Book details view – cover, title, author, order form<br>
🛒 Order physical copy – address & phone number validation<br>
📧 Confirmation dialog on successful order (email simulation)<br>
🏬 Store locator – list of physical store locations<br>
🎠 Image carousel for store showcases with next/prev buttons<br>
🎨 Reusable UI components – buttons, cards, navigation menu with states<br>
🖼️ Custom backgrounds & overlays – consistent design system (colors, text styles)<br>
🔁 Interactive prototyping – hover, mouse‑down, carousel animation, page redirects<br>

## 🗂️ Project Structure

```
app/
  src/main/java/com.example.dclassicsbooks        # Source code
  src/main/res/                                   # Resources (drawables, layouts, fonts, etc.)
  src/main/AndroidManifest.xml                    # App manifest
  build.gradle                                    # Module build config
build.gradle.kts                                  # Project build config
settings.gradle.kts                               # Gradle settings
gradle/                                           # Gradle wrapper & versions
build/                                            # Build outputs & reports
```

## 🚀 Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/junssekut/AnimeDxD.git
   ```
2. **Open in Android Studio:**
    - Import the project as a Gradle project.
3. **Build and Run:**
    - Use the Gradle wrapper (`./gradlew build`) or Android Studio's build/run buttons.
